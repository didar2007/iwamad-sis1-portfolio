## Projects

- Personal Profile Page — HTML and CSS project from Week 1.
- React + TypeScript Profile Card — React and TypeScript project from Week 3.
- React Portfolio — multi-page React project with routing, shared state, testing and GitHub Pages from Week 4.

## Design Decisions

1. I used a simple dark and light color system so the website remains readable and comfortable in different modes.

2. I used a consistent spacing and typography system to make the page clean and easy to navigate.

3. I used responsive layouts that change from multiple columns on desktop to a single-column layout on smaller screens.

## Contact

The contact form uses JavaScript validation and does not actually send messages. It displays specific validation messages for empty fields and invalid email addresses.
